# Babies Nail Studio Mockup

Este es un proyecto de desarrollo web premium diseñado específicamente para un salón de uñas de alta gama. La aplicación ha sido desarrollada utilizando tecnologías modernas para ofrecer una experiencia de usuario fluida, estética y profesional.

## Características Principales

*   **Diseño Estético Premium**: Interfaz basada en una paleta de colores rosa pastel y pastel suave, con un enfoque en la elegancia y la limpieza visual.
*   **Modo Nocturno Integrado**: Sistema de cambio de tema (Light/Dark) que adapta todos los componentes a una versión oscura basada en tonos púrpuras y negros profundos.
*   **Visualización de Portafolio en 3D**: Implementación de tres filas de carruseles con efecto Coverflow tridimensional, permitiendo una navegación dinámica por las colecciones de diseños.
*   **Galería en Cuadrícula**: Sección de portafolio organizada en una cuadrícula de 3x3 con efectos de interacción y respuesta táctil.
*   **Navegación Inteligente**: Menú de navegación optimizado con enlaces internos que dirigen a las secciones de Inicio, Servicios, Portafolio y Contacto.
*   **Diseño Responsivo**: La interfaz se adapta perfectamente a dispositivos móviles, tablets y ordenadores de escritorio.

## Tecnologías Utilizadas

*   **Next.js**: Framework de React para el renderizado y la estructura de la aplicación.
*   **Tailwind CSS**: Framework de utilidades CSS para un diseño rápido y consistente.
*   **Framer Motion**: Librería de animaciones para los efectos 3D, transiciones y micro-interacciones.
*   **Lucide React**: Set de iconos vectoriales para la interfaz.

## Instalación y Uso

Para ejecutar este proyecto en un entorno local, siga estos pasos:

1. Clonar el repositorio.
2. Navegar a la carpeta del proyecto: `cd mx`
3. Instalar las dependencias: `npm install`
4. Iniciar el servidor de desarrollo: `npm run dev`
5. Abrir el navegador en: `http://localhost:3000`

## Notas de Desarrollo

Este proyecto ha sido diseñado como una maqueta funcional. Los textos y las imágenes actuales sirven como marcadores de posición (placeholders) para ser sustituidos por contenido real según las necesidades del cliente.
