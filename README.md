# Babies Nail Studio Mockup

Maqueta web premium para salon de uñas. Desarrollada con Next.js y Tailwind CSS. Posee estetica rosa, modo nocturno, galeria 3x3 y portafolio interactivo con carruseles 3D Coverflow. Diseño responsivo y optimizado para una experiencia de lujo. Incluye navegacion inteligente y animaciones avanzadas con Framer Motion. Todo sin contenido real.
